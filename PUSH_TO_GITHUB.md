# Push to GitHub
1. Create an EMPTY repo on github.com named `rfp-document-generator` (no README/license).
2. If your username or repo name differs: `git remote set-url origin https://github.com/<user>/<repo>.git`
3. Optional: `git config user.name "Your Name"` and `git config user.email "you@example.com"`
   (the first commit used a placeholder identity; `git commit --amend --reset-author --no-edit` fixes it)
4. `git push -u origin main`
